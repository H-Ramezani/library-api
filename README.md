# Library API

یک رابط برنامه‌نویسی ساده برای مدیریت کتابخانه، ساخته‌شده با Python و FastAPI.

## امکانات

- نمایش همه کتاب‌ها
- افزودن کتاب جدید
- دریافت کتاب با شناسه
- ویرایش اطلاعات کتاب
- حذف کتاب
- اعتبارسنجی داده‌های ورودی
- مدیریت خطای کتاب ناموجود

## فناوری‌ها

- Python
- FastAPI
- Uvicorn
- Pydantic

## راه‌اندازی

### ۱. ساخت محیط مجازی

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### ۲. نصب وابستگی‌ها

```powershell
python -m pip install -r requirements.txt
```

### ۳. اجرای برنامه

```powershell
python -m uvicorn main:app --reload
```

### ۴. مستندات API

پس از اجرای برنامه، آدرس زیر را در مرورگر باز کن:

http://127.0.0.1:8000/docs

## مسیرهای API

| متد | مسیر | کاربرد |
|---|---|---|
| GET | `/` | پیام خوشامدگویی |
| GET | `/books` | نمایش همه کتاب‌ها |
| POST | `/books` | افزودن کتاب |
| GET | `/books/{book_id}` | دریافت یک کتاب |
| PATCH | `/books/{book_id}` | ویرایش کتاب |
| DELETE | `/books/{book_id}` | حذف کتاب |

## نمونه اطلاعات کتاب

```json
{
  "title": "Clean Code",
  "author": "Robert C. Martin",
  "year": 2008
}
```

شناسه‌ی کتاب به‌صورت خودکار تعیین می‌شود.

## ذخیره‌سازی

اطلاعات کتاب‌ها در حافظه نگهداری می‌شوند و پس از راه‌اندازی مجدد برنامه، تغییرات از بین می‌روند. این پروژه از پایگاه داده استفاده نمی‌کند.
